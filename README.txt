# Site web 4ALL ENERGY

## Contenu
- `index.html` : accueil
- `electricite-generale.html` : électricité générale
- `panneaux-solaires.html` : photovoltaïque
- `bornes-recharge.html` : bornes de recharge IRVE
- `climatisation.html` : climatisation
- `services-industriels.html` : services industriels
- `contact.html` : contact et demande de devis
- `assets/styles.css` : styles responsive
- `assets/site.js` : menu mobile et formulaire de contact
- `assets/logo-ae.jpg` : logo fourni, si le fichier a pu être intégré

## Tester le site
Ouvrir `index.html` dans un navigateur. Aucun serveur ni framework n'est nécessaire pour prévisualiser le site.

## Mettre en ligne
Téléverser le contenu du dossier sur l'hébergement web, dans le dossier public du site (souvent `public_html` ou `www`). Conserver l'arborescence des fichiers.

## À finaliser avant publication
1. Vérifier le logo dans l'en-tête et remplacer le fichier par une version haute résolution/PNG transparent si disponible.
2. Ajouter les mentions légales, la politique de confidentialité et les informations de l'entreprise nécessaires.
3. Vérifier les textes, prestations réellement proposées, qualifications et périmètres d'intervention.
4. Le formulaire actuel ouvre le logiciel de messagerie du visiteur via `mailto:` ; il ne stocke ni ne transmet les demandes sur un serveur. Pour un formulaire en ligne, connecter un service ou un backend.
5. Ajouter des photos réelles de chantiers avec les autorisations nécessaires, et éventuellement les liens vers les réseaux sociaux.

## Personnalisation
Les couleurs principales sont définies au début de `assets/styles.css` dans `:root`.
